# Imtui Backlog

## Feature backlog

- [ ] Styles - essentially want to make it easy to define a color scheme for Imtui, like Dear ImGui.

## Widget backlog

- [ ] List
  - Basic unordered/bulleted list
- [ ] Tree / TreeNode
  - Expandable/collapsible with children
- [ ] Panel
  - Has title bar which has an accent background color (like Dear ImGui has blue titlebars), and the panel has a dark gray background color (stands out from non-panel content). Different colors when unfocused. Focus can move between panels. Widget focus state is remembered inside a given panel.
- [ ] VStack
- [ ] HStack
- [ ] Modal
- [ ] Select
  - Type to fuzzy filter options, or use arrow keys to select
- [ ] Range/Scalar input
- [ ] Tabs
- [ ] Accordion
  - List of tabs, of which only one can be expanded inline at a given time
