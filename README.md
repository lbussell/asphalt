# Asphalt

Asphalt is an [immediate-mode](https://caseymuratori.com/blog_0001) terminal user
interface library for .NET.

## Goal

Asphalt's goal is to make TUI programming as easy as possible.

## Documentation

- [Widget gallery](docs/widgets.md)
- [Samples](samples/README.md)

### Details

- API similar to [Dear ImGui](https://github.com/ocornut/imgui/)
- Opinionated: makes sane choices for you
- Keyboard-driven: no mouse support
